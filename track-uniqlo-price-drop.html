How to track a UNIQLO price drop with the tag code

Last checked 2026-11-27

Find the 6-digit code on the tag, type it into PriceDog (or scan the barcode), and track the item. You will see its price history in NT$ and get a push when it goes on sale.

Find the code

The 6-digit product code is printed on the tag. You can also scan the tag barcode with the camera; the 6-digit code can be typed instead if you prefer not to allow camera access.

Track it

  1. Open PriceDog and use product code search.
  2. Open the product page and look at the price history chart.
  3. Track the item, choosing the colors and sizes you care about.
  4. Keep notifications on.

Read the price trend

The chart shows the full price trend in NT$. Items are labelled when they reach their historical low or have just gone on sale.

Writing prices down yourself is a general approach. The chart, labels and tracking list are app features; prices update daily and are for reference only, since actual prices follow the official brand channels.

FAQ

Where is the code?

It is the 6-digit code printed on the product tag.

How often do prices update?

Daily, for reference only.
